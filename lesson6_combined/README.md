# Урок 6: AI-Агент у Discord

У гэтым прыкладзе мы пераносім нашых AI-агентаў з інструментамі (tools) у асяроддзе Discord. 

## Апісанне

Бот рэагуе на паведамленні ў пэўным канале Discord або ў прыватных паведамленнях. Ён выклікае агента (`agentApp`), які можа выкарыстоўваць розныя прылады для адказу. У кодзе падтрымліваецца гісторыя паведамленняў і нават апрацоўка ўкладанняў малюнкаў (`imageUrl`), якія дасылаюцца карыстальнікамі.

## Як запусціць

1. Усталюйце залежнасці:
   ```bash
   bun install
   ```

2. Дадайце `.env` з вашым Discord токенам і ключамі LLM:
   ```env
   DISCORD_BOT_TOKEN=ваш_discord_токен
   OPENAI_API_KEY=ваш_openai_ключ
   ```

3. Запусціце агента:
   ```bash
   bun run index.ts
   ```
> **Заўвага:** У `index.ts` жорстка зашыты ID канала `1374368491771002970` для абмежавання зносін. Не забудзьцеся змяніць яго на ID вашага ўласнага канала для тэставання.
