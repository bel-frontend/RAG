# Урок 1: Базавы RAG з Ollama і Qdrant

Гэты ўрок дэманструе стварэнне базавага Retrieval-Augmented Generation (RAG) пайплайну з выкарыстаннем лакальных мадэляў праз Ollama і вектарнай базы дадзеных Qdrant.

## Апісанне

У гэтым прыкладзе:
1. Дакументы (PDF) загружаюцца і разбіваюцца на часткі.
2. Тэкставыя часткі ператвараюцца ў вектары (embeddings) з дапамогай лакальнай мадэлі Ollama.
3. Вектары захоўваюцца ў лакальным інстансе Qdrant.
4. Пры выкананні запыту (`index.ts`) адбываецца пошук па вектарнай базе, а знойдзеныя дадзеныя перадаюцца ў LLM (напрыклад, Gemma3 праз Ollama) для генерацыі адказу на беларускай мове.

## Файлы
- `pdf_loader/pdf-loader.ts` - Загрузка PDF дакументаў.
- `create_collection.ts` - Стварэнне калекцыі ў Qdrant.
- `embedding.ts` - Стварэнне і захаванне embeddings.
- `index.ts` - Галоўны скрыпт для пошуку па базе і генерацыі адказу.

## Як запусціць

1. Усталюйце залежнасці:
   ```bash
   bun install
   ```

2. Запусціце Qdrant лакальна (напрыклад, праз Docker з `qdrant/docker-compose.yml`, калі такі ёсць, або глабальна).
3. Пераканайцеся, што ў вас працуе [Ollama](https://ollama.com/) з усталяванай мадэллю (напрыклад, `gemma3:12b` або іншай, якая пазначана ў `index.ts`).

4. Калі неабходна спачатку стварыць калекцыю і запоўніць яе:
   ```bash
   bun run create_collection.ts
   bun run embedding.ts
   ```

5. Выканайце пошукавы запыт і атрымайце адказ:
   ```bash
   bun run index.ts
   ```
