# Урок 3: Telegram-бот і Structured Output

У гэтым уроку дэманструецца стварэнне Telegram-бота, які выкарыстоўвае магчымасці LLM для структураванага вываду (Structured Output) з дапамогай Zod-схем.

## Апісанне

Бот працуе як AI-адміністратар канала. Карыстальнік дасылае паведамленне, а бот вызначае, ці з'яўляецца тэкст спамам/скамам (scam). Адказ мадэлі (Mistral/OpenAI) строга фарматаваны дзякуючы метаду `withStructuredOutput` ад LangChain і змяшчае булевы статус і падрабязнае тлумачэнне.

## Тэхналогіі
- Telegram Bot API
- Zod (для тыпізацыі адказу LLM)
- Docker (уключаны Dockerfile і docker-compose.yml для дэплою)

## Як запусціць

1. Усталюйце залежнасці:
   ```bash
   bun install
   ```

2. Стварыце файл `.env` (па ўзоры `.env.example`) і дадайце токен вашага бота, які можна атрымаць у BotFather:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен
   ```

3. Запуск у рэжыме распрацоўкі:
   ```bash
   bun run index.ts
   ```

4. Запуск праз Docker (апцыянальна):
   ```bash
   docker-compose up -d
   ```
