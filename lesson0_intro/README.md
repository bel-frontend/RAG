# Уводзіны ў курс: RAG і AI-агенты

Гэты курс — практычны шлях ад простага RAG-пайплайну да поўнацэнных AI-агентаў з інструментамі, MCP і воркшопамі на рэальных задачах. Усе прыклады на **TypeScript**, рантайм — **Bun**.

## 📌 Пра што гэты курс

Гэты курс навучыць вас ствараць інтэлектуальныя сістэмы і дадаткі новага пакалення. Мы пройдзем шлях ад простых скрыптоў да складаных агентаў.

### 🧩 Простымі словамі: што ўсё гэта значыць?

Калі вы толькі пачынаеце, такія тэрміны, як RAG або AI-агент, могуць падавацца складанымі. Вось як яны працуюць на простых прыкладах:

- **Што такое RAG (Retrieval-Augmented Generation)?**
  Уявіце, што штучны інтэлект (ШІ) — гэта студэнт на іспыце. Звычайна ён адказвае па памяці і можа нешта пераблытаць ці выдумаць (гэта называецца "галюцынацыя"). **RAG** — гэта іспыт з "адкрытай кнігай". Калі вы задаяце пытанне, праграма спачатку знаходзіць патрэбны абзац у *вашых уласных* дакументах (напрыклад, у кнігах, інструкцыях ці PDF-файлах), перадае гэты тэкст штучнаму інтэлекту і кажа: "Напішы адказ толькі на аснове гэтага тэксту". Такім чынам вы атрымліваеце дакладныя і праўдзівыя адказы.
  
- **Што такое AI-агент?**
  Звычайны чат-бот (напрыклад, базавы ChatGPT) проста выдае тэкст у адказ на пытанне. **Агент** — гэта больш самастойны "работнік". Ён умее будаваць планы і выпраўляць свае памылкі. Напрыклад, калі вы просіце "даведайся надвор'е ў Мінску і парай, ці браць парасон", агент сам складзе план: "1. Даведацца надвор'е. 2. Прааналізаваць яго. 3. Напісаць вам параду".

- **Што такое Tools (Інструменты)?**
  Сам па сабе штучны інтэлект знаходзіцца ў ізаляцыі — ён не мае доступу да актуальнага інтэрнэту ці вашых файлаў. **Інструменты** — гэта "рукі" і "вочы" агента. Мы можам даць яму інструмент "паглядзі надвор'е", "адкрый файл", або "выканай матэматычны падлік", каб ён мог рабіць рэальныя справы.

- **Вектарная база дадзеных (напрыклад, Qdrant)**
  Каб хутка знаходзіць інфармацыю ў тысячах дакументаў, мы ператвараем тэкст у лічбы (вектары). Вектарная база шукае інфармацыю не па супадзенні літар, а **па сэнсе**. Напрыклад, калі вы шукаеце "сабака", яна знойдзе і тэкст са словам "шчанюк", бо яны блізкія па значэнні.

Працоўная мова прыкладаў, промптаў і дакументацыі — **беларуская**.

## 🛠 Як усталяваць неабходныя праграмы (Падрыхтоўка асяроддзя)

Каб паспяхова праходзіць курс і запускаць код, вам спатрэбіцца наступнае праграмнае забеспечанне. 

### 1. Bun (Асноўны JavaScript/TypeScript рантайм)
Увесь код у курсе выкарыстоўвае хуткі рантайм Bun замест Node.js.
- **macOS / Linux**: 
  ```bash
  curl -fsSL https://bun.sh/install | bash
  ```
- **Windows**: 
  ```powershell
  powershell -c "irm bun.sh/install.ps1 | iex"
  ```
*Праверыць усталёўку: `bun --version`*

### 2. Git
Неабходны для кланавання гэтага рэпазіторыя.
- **macOS**: `brew install git` (або ўсталюецца аўтаматычна з Xcode Command Line Tools)
- **Linux (Ubuntu/Debian)**: `sudo apt install git`
- **Windows**: Спампаваць з [git-scm.com](https://git-scm.com/)

*Кланаванне праекта:*
```bash
git clone <спасылка_на_рэпазіторый>
cd RAG
```

### 3. Docker і Docker Compose (Для Qdrant і ботаў)
Docker спатрэбіцца для запуску вектарнай базы дадзеных (Qdrant) і некаторых воркшопаў.
- Спампуйце і ўсталюйце **Docker Desktop** для вашай сістэмы з [docker.com](https://www.docker.com/products/docker-desktop/).
- Пераканайцеся, што Docker запушчаны перад пачаткам працы з урокамі.

### 4. Ollama (Для лакальных нейрасетак)
Патрэбна для ўрокаў 1, 2 і 5, каб запускаць LLM лакальна без інтэрнэту і аплаты за API.
- Спампуйце з [ollama.com](https://ollama.com/) і ўсталюйце.
- Пасля ўсталёўкі адкрыйце тэрмінал і запампуйце мадэль, якая будзе выкарыстоўвацца:
  ```bash
  ollama run gemma3:12b
  ```
  *(Мадэль пачне спампоўвацца. Гэта можа заняць час у залежнасці ад інтэрнэту. Таксама вы можаце выкарыстаць іншыя даступныя мадэлі).*

### 5. Qdrant (Вектарная база дадзеных)
Мы выкарыстоўваем яе для захавання кантэксту (embeddings).
Самы просты спосаб запусціць Qdrant — праз Docker. У тэчках урокаў ёсць файлы `docker-compose.yml`. Для запуску дастаткова выканаць (у тэчцы ўрока):
```bash
docker-compose up -d
```
Таксама можна выкарыстоўваць [Qdrant Cloud](https://qdrant.to/cloud) (бясплатны кластар) і проста дадаць URL у `.env`.

### 6. Tesseract OCR і Poppler (Апцыянальна, для ўрока 11)
Спецыяльныя ўтыліты для распазнавання тэксту на малюнках і адсканаваных PDF.
- **macOS**: `brew install tesseract poppler` (і дадатковыя мовы, напрыклад `tesseract-lang`)
- **Linux (Ubuntu)**: `sudo apt install tesseract-ocr poppler-utils`
- **Windows**: Складаней, спатрэбіцца ўсталёўшчык tesseract і даданне яго ў PATH.

### 7. Рэдактар кода
Рэкамендуецца выкарыстоўваць **VS Code** або **Cursor** (вельмі зручны рэдактар з убудаваным AI).
- [Спампаваць VS Code](https://code.visualstudio.com/)
- [Спампаваць Cursor](https://www.cursor.com/)

## ⚙️ Наладка асяроддзя (.env файлы)

Шматлікім скрыптам спатрэбяцца API-ключы (напрыклад, для OpenAI, Telegram і Discord). 
1. У корані праекта (ці ў тэчцы ўрока) звычайна ёсць файл `.env.example`.
2. Скапіруйце яго і назавіце `.env`:
   ```bash
   cp .env.example .env
   ```
3. Адкрыйце `.env` у рэдактары і ўпішыце туды свае ключы. 
   - `OPENAI_API_KEY` — ключ ад OpenAI.
   - `TELEGRAM_BOT_TOKEN` — ключ для бота (атрымліваецца ў BotFather у Telegram).

**Ніколі не каміцьце файл `.env` у публічны рэпазіторый!** Ён ужо дададзены ў `.gitignore`.

## 📚 Структура курса і парадак праходжання

Кожны ўрок — асобная тэчка. Рэкамендуецца праходзіць па парадку: кожны наступны ўрок апіраецца на ідэі папярэдніх.

У кожнай тэчцы ўрока неабходна спачатку ўсталяваць залежнасці:
```bash
cd lessonX_назва
bun install
```

| Урок | Тэчка | Тэма |
|------|-------|------|
| 0 | `lesson0_intro/` | Уводзіны і наладка (гэты файл) |
| 1 | `lesson1_phi4/` | Базавы RAG: Ollama embeddings + Qdrant + лакальная LLM |
| 2 | `lesson2_openai/` | RAG з OpenAI embeddings замест лакальных |
| 3 | `lesson3_formatted_result/` | Telegram-бот са структураваным вывадам (Zod) |
| 4 | `lesson4_agent/` | AI-агент з інструментамі (надвор'е, прыказкі) у Telegram |
| 5 | `lesson5_images/` | Аналіз выяў у Telegram-боце (vision-мадэлі) |
| 6 | `lesson6_combined/` | Агент у Discord з расшыранымі інструментамі |
| 7 | `lesson7_chain_models/` | Ланцужкі LangChain (`RunnableSequence`) |
| 8 | `lesson8_mcp/` | MCP-сервер (Model Context Protocol) з HTTP-транспартам |
| 9 | `lesson9_langchain/` | LangChain v1 і LangGraph: агенты, графы, structured output |
| 10 | `lesson10_workshop/` | **Воркшоп:** MD-рэцэнзент — агент для праверкі Markdown |
| 11 | `lesson11_workshop_rag_chat/` | **Воркшоп:** PDF → embeddings → Qdrant → чат з RAG-агентамі |
| 12 | `lessons12_skills/` | Agent Skills — паўторнае выкарыстанне логікі агента як скіла |

### Логіка нарастання складнасці

1. **Урокі 1–2** — Фундамент RAG: PDF → чанкі → embeddings → Qdrant → пошук → адказ LLM.
2. **Урокі 3–6** — Інтэграцыя з месенджарамі (Telegram, Discord), з'яўленне агентаў і першых Tools.
3. **Урокі 7–9** — LangChain-экасістэма: ланцужкі, MCP, сучасны API LangChain v1 і графы LangGraph.
4. **Урокі 10–11** — Воркшопы «пад ключ»: гатовыя праекты, якія можна адаптаваць для сваіх патрэб.
5. **Урок 12** — Skills: як спакаваць логіку і распаўсюджваць паводзіны агента.
