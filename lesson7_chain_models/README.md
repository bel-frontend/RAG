# Урок 7: Ланцужкі LangChain (RunnableSequence)

Гэты ўрок дэманструе працу са складанымі ланцужкамі выканання (chains) з выкарыстаннем LangChain v1. 

## Апісанне

Тут рэалізаваны працэс апрацоўкі тэксту, які складаецца з некалькіх паслядоўных зваротаў да LLM (напрыклад, GPT-4o):
1. **Аналіз і пераклад**: Праверка тэматыкі навіны (тэхналогіі, ІТ і г.д.) і пераклад на беларускую мову разам з рэзюмэ.
2. **Карэктура**: Дадатковы праход LLM па выпраўленні магчымых арфаграфічных ці лексічных памылак у перакладзе.

Выкарыстанне `RunnableSequence` дазваляе лагічна звязаць гэтыя этапы, пры гэтым захоўваючы вынікі кожнага з іх для фінальнага вываду (арыгінал, пераклад, карэктура).

## Як запусціць

1. Усталюйце залежнасці:
   ```bash
   bun install
   ```

2. Пераканайцеся, што ў вашым асяроддзі даступныя адпаведныя API-ключы (напрыклад, OpenAI ў `.env`):
   ```env
   OPENAI_API_KEY=ваш_ключ
   ```

3. Запусціце ланцужок:
   ```bash
   bun run index.ts
   ```

Таксама вы можаце праверыць файл `test.ts`, каб паглядзець на дадатковыя эксперыменты.
