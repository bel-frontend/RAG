# Урок 1: Знаёмства з AI-first IDE і распрацоўкай з дапамогай ШІ

Сёння распрацоўка праграмнага забеспячэння перажывае фундаментальны зрух. Рэдактары кода ператвараюцца з проста тэкставых рэдактараў з падсветкай сінтаксісу ў інтэлектуальных суаўтараў. 

Гэты ўрок прысвечаны **AI-first IDE** — асяроддзям распрацоўкі, дзе штучны інтэлект з'яўляецца цэнтральным элементам інтэрфейсу, а не проста дадатковым плагінам.

---

## 💻 Чаму AI-first IDE змяняюць правілы гульні?

Традыцыйныя AI-аўтакампліты (накшталт базавага GitHub Copilot) проста падказвалі наступны радок кода. Сучасныя AI-рэдактары працуюць на ўзроў�## 🛠️ Агляд асноўных інструментаў распрацоўкі

На працягу гэтага курса мы рэкамендуем выкарыстоўваць адзін з наступных варыянтаў. Ніжэй прыведзены падрабязныя інструкцыі па іх выкарыстанні і наладцы.

### 1. Cursor (🏆 Рэкамендуемы выбар)
Cursor — самы папулярны рэдактар на базе VS Code, у якім AI-функцыі інтэграваны на ўзроўні ядра.
*   **Як карыстацца чатам (Cmd+L / Ctrl+L):** Адкрывае бакавы чат. Вы можаце выкарыстоўваць сімвал `@`, каб дадаць у кантэкст канкрэтныя файлы (`@file.ts`), функцыі ці нават увесь праект (`@codebase`).
*   **Як карыстацца Composer (Cmd+I / Ctrl+I):** Гэта рэжым агента (аўтаномнага рэдагавання). Напішыце: *"Ствары новы TypeScript файл для падліку сумы і напішы да яго тэсты"*. Cursor сам створыць файлы, выканае каманды ў тэрмінале і прапануе вам прыняць змены.
*   **Рэдагаванне па месцы (Cmd+K / Ctrl+K):** Вылучыце кавалак кода, націсніце спалучэнне клавіш і напішыце промпт (напрыклад, *"дадай апрацоўку памылак"*). Код будзе зменены прама ў файле.

### 2. VS Code + GitHub Copilot (Класічны выбар)
Калі вы хочаце застацца на стандартным VS Code, выкарыстоўвайце афіцыйнае пашырэнне **GitHub Copilot** і **GitHub Copilot Chat**.
*   **Аўтакампліт (Аўтазапаўненне):** Па меры напісання кода Copilot будзе прапаноўваць шэры тэкст-падказку. Націсніце `Tab`, каб прыняць яго.
*   **Бакавы чат (Cmd+Ctrl+L / Ctrl+Shift+L):** Дазваляе задаваць пытанні па кодзе. Выкарыстоўвайце сімвал `#`, каб перадаць кантэкст (напрыклад, `#file:index.ts` або `#codebase` для ўсяго праекта).
*   **Inline Chat (Cmd+I / Ctrl+I):** Выклікае невялікае акно прама ў рэдактары для змены вылучанага кода ці стварэння новага па промпту.

## 🎯 Практычныя практыкаванні для трэніроўкі

Каб асвоіцца з выбраным рэдактарам, выканайце наступныя заданні перад пачаткам працы з кодам:

### Заданне 1: Выкарыстанне кантэксту
1. Адкрыйце каранёвую тэчку гэтага праекта ў Cursor ці VS Code.
2. Адкрыйце AI-чат і запытайце: 
   *"Растлумач, у чым розніца паміж Урокам 0 і Урокам 2, выкарыстоўваючы толькі файлы майго праекта"* (у Cursor выкарыстоўвайце `@codebase` для кантэксту, у VS Code з Copilot — `#codebase`).
3. Паглядзіце, як рэдактар прааналізуе структуру тэчак і дакументацыю.

### Заданне 2: Рэдагаванне па месцы (Inline Edit)
1. Стварыце ў тэчцы гэтага ўрока часовы файл `test.ts`.
2. Напішыце там простую функцыю:
   ```typescript
   function sum(a, b) {
     return a + b;
   }
   ```
3. Вылучыце гэтую функцыю, выклічце рэдагаванне праз AI (`Cmd+K` у Cursor або `Cmd+I` / `Ctrl+I` у VS Code) і папрасіце: *"Перапішы на TypeScript з тыпізацыяй і дадай JSDoc на беларускай мове"*.
4. Прыміце прапанаваныя змены (`Accept`).

### Заданне 3: Аўтаномнае стварэнне кода (Composer / Agent Mode)
1. Выклічце Composer (у Cursor `Cmd+I`) або Copilot Edits / Chat (у VS Code `Cmd+I`).
2. Напішыце промпт: *"Ствары новы файл `calculator.ts`, які будзе мець функцыі для складання, аднімання, множання і дзялення, а таксама напішы функцыю, якая выкліча іх з тэставымі лічбамі і выведзе вынік у кансоль. Запусці гэты файл праз Bun"*.
3. Дазвольце AI выканаць каманды і стварыць файлы. Пераканайцеся, што файл паспяхова запусціўся і вывеў вынік.
