# AWS lessons

## [AIF-C01 — AWS Certified AI Practitioner](aif-c01-study/)

Падручнік і трэнажор на беларускай мове для падрыхтоўкі да экзамену **AWS Certified AI Practitioner (AIF-C01)**. Працуе ў браўзеры без інтэрнэту і без зборкі.

| Файл | Што ўнутры |
|---|---|
| [`index.html`](aif-c01-study/index.html) | Дадатак: тэорыя па 28 тэмах са схемамі, трэнажор з разборам, сімуляцыя экзамену, карткі, слоўнік, статыстыка |
| [`ГАЙД_AIF-C01.md`](aif-c01-study/ГАЙД_AIF-C01.md) / `.html` | Падручнік адным дакументам (для чытання і друку) |
| `theory.js` | Тэорыя па тэмах і карткі |
| `glossary.js` | Слоўнік (~200 тэрмінаў), падказкі пры навядзенні на тэрмін |
| `data.js` | Пытанні для трэнажора: 98 па тыповых памылках + 52 базавыя |

Як карыстацца: склануй рэпазіторый і адкрый `aif-c01-study/index.html` у браўзеры.

Па жаданні можна дадаць свае пытанні ў файл `aif-c01-study/data_udemy.js` (ён у `.gitignore`), фармат той самы, што ў `data.js`: `window.QUESTIONS = (window.QUESTIONS||[]).concat([...])`.
