# Урок 5: Аналіз выяў у Telegram з Vision-мадэлямі

Гэты ўрок паказвае, як інтэграваць AI-мадэлі з магчымасцю аналізу выяў (Vision) у Telegram-бота. 

## Апісанне

Калі карыстальнік дасылае малюнак, бот спампоўвае яго, канвертуе ў Base64 фармат і перадае мадэлі разам з промптам. Мадэль (напрыклад, Gemma 3) аналізуе малюнак, знаходзіць тэкст (калі ён ёсць) і дае падрабязнае апісанне змесціва.

## Як запусціць

1. Усталюйце залежнасці:
   ```bash
   bun install
   ```

2. Наладзьце `.env` з токенам бота і ключамі:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен
   ```

3. Запусціце бота лакальна:
   ```bash
   bun run index.ts
   ```

Альбо выкарыстоўвайце прадастаўлены `docker-compose.yml` для запуску праз Docker:
```bash
docker-compose up -d
```
